# CojectiveTask

A responsive industrial website recreated from the provided design reference using HTML, CSS, and JavaScript.

## Tech Stack

* HTML5
* CSS3
* JavaScript
* Netlify for deployment

## Features

* Responsive industrial website layout
* Hero section with video background
* Product showcase
* Industry/application sections
* Interactive UI elements
* Accessible semantic HTML and ARIA attributes
* Optimized navigation and section linking
